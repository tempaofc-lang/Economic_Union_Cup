## 0. 前提

### 0.1 重新分配的依据：不再按原始标签，按「能不能天天见面 + 谁扛得住」

原始分工方案（[成员安排方案](../成员安排方案.docx)）给的定位是：古宇轩=智能体逻辑、李彤=界面、杜佳润=视频、吴夏云=文档、李东瑞=测试。这套标签是开会时随手填的，其中两条现在看明显不合理：

- **吴夏云做"文档"是错配。** 政务知识库 → Prompt 构造 → 评测用例，这三件事是**同一条链**。把内容给人 A、prompt 给人 B、用例没人管，等于人为制造两次交接摩擦。而她本来要整理的就是政务事项材料的文字，写的恰好是知识库正文。
- **李东瑞做"测试"是浪费。** 他是团队负责人。让负责人专职做 QA，等于没有人对"集成是否通"负责。他应该拿后端接口层和封版提交——**谁守契约，谁就该拥有契约的落地代码。**

另外两条真实约束：

**约束一：同班物理位置。** 按承诺书，古宇轩、吴夏云、杜佳润三人是**地理与环境学院 · 地理信息科学（计算机科学与技术双学位）· 25 级**，完全同班。李东瑞（人工智能学院·计算机科学与技术）、李彤（人工智能学院·软件工程·区块链）是另外两个院。

→ 结对学习、结对调试顺着班级走，跨院的靠线上。

**约束二：全员大二，AI 与前后端基础普遍薄弱（古宇轩除外）。**

→ 不能给任何人叠三个角色。一人一条泳道，配一个"副责"仅用于备份和评审，**副责不承担工期**。

### 0.2 分工不再按「有没有显卡」来切

有 **5 台独显机器**之后，"A 组有卡、B 组无卡"这条前提失效。

**新切分标准是「按模块 + 按文件所有权」：**

- 每个人**只改自己名下的文件**，通过**冻结的接口契约**协作。
- 一个人属于 A 还是 B，取决于他**改的是哪个文件**，不取决于机器配置。
- 好处：A 组不再是人手瓶颈，B 组也不必"等权重"才能动工。

### 0.3 初赛只看材料，没有现场答辩

### 0.4 「静态手语词」= 孤立词，理解是对的，实现要澄清一次

"较为孤立（非成串）的词汇"，学术上就是**孤立词识别**，这个界定站得住，不用改。

但要澄清：**"孤立"指每次只识别一个词，不等于"用一张静止画面就能识别"。** 手语的词带动作，单帧分类对绝大多数词无效。

好消息：**不需要推翻现有架构**。接口、界面、词表都不动，只需把识别层内部从「单帧判决」改成「短片段判决」（详见 §6）。

## 3. 接口契约（冻结）

5 个人并行的前提。**字段名一旦定下，改动必须走「群内通知 + `docs/api.md` 升版本号」。**

### 3.1 端点总表

| 方法 | 路径 | 作用 | 归属 |
|---|---|---|---|
| GET | `/api/health` | 存活检查 | 李东瑞 |
| GET | `/api/vocab` | 当前词表 | 李东瑞 |
| POST | `/api/recognize` | 视频/帧 → 词序列 | A 组（李东瑞守契约） |
| POST | `/api/agent` | 词序列 → 译文 + 导办回答 | 古宇轩 |
| POST | `/api/session/{sid}/reply` | 工作人员回复 | 古宇轩 |
| GET | `/api/session/{sid}/history` | 历史记录 | 古宇轩 |

### 3.2 `POST /api/recognize`

请求：`multipart/form-data`，字段 `file` = 视频（mp4/mov/avi）。

```json
{
  "engine": "mock",
  "elapsed_ms": 812,
  "tokens": [
    {"word": "身份证", "conf": 0.93, "bbox": [190, 110, 390, 340],
     "t_start": 1.24, "t_end": 1.61}
  ],
  "rejected": [{"word": "未知动作", "conf": 0.41}],
  "frames_total": 34
}
```

约定：
- `tokens` 只放**通过阈值**的词，按时间序。
- `rejected` 放被阈值过滤的 → 界面显示"已过滤 N 个"，**这是防抖演示的数据来源**。
- `engine` 只能是 `"mock"` 或 `"real"`。**成片里出现 `"mock"` 就是事故**（红线 R2）。
- `bbox` 用 `[x1,y1,x2,y2]` 整数数组，坐标系 760×480。

### 3.3 `POST /api/agent`

请求：

```json
{"words": ["身份证", "丢失", "补办"], "session_id": "s-001", "staff_reply": null}
```

响应：

```json
{
  "translation": "工作人员您好，我的身份证丢失了，请问怎么办理补办？",
  "answer": "【政务导办回答】请携带户口本原件，先到 2 号人像采集室免费拍照，再到 3 号户政窗口办理，工本费 40 元。",
  "confirm_card": {
    "title": "身份证补办",
    "materials": ["居民户口簿", "本人到场采集人像"],
    "window": "3 号户政窗口",
    "fee": "40 元"
  },
  "clarify": null,
  "tool_calls": [
    {"name": "query_gov_kb", "args": {"item": "身份证补办"}, "ok": true}
  ],
  "mode": "llm"
}
```

三个必须读懂的设计点（古宇轩、李彤、吴夏云都要看）：

- **`clarify` 是加分项，不是可选项。** 词太少（≤1）或语义模糊时，Agent 不硬猜：

  ```json
  "clarify": {"question": "请问您要办理身份证还是社保卡？", "options": ["身份证", "社保卡", "医保"]}
  ```

  李彤渲染成三个大按钮让工作人员点。**这一手把"识别不准"的短板变成"Agent 会主动沟通"的长板。**

- **`tool_calls` 要真实回显。** 界面做一个可展开的「Agent 决策轨迹」，显示调了哪个工具、拿到什么。**这是评委判断"你到底是不是智能体"的直接证据。**

- **`mode` 只能是 `"llm"` 或 `"rule"`。** 断网自动降级规则引擎，界面显示降级标识（决赛兜底）。

### 3.4 摄像头

**两天冲刺不做 WebSocket。** 用最笨最稳的：

```
getUserMedia 取帧 → canvas → toDataURL → 每 200ms POST /api/recognize
```

5fps 对手语演示够用，代码量小到李彤独立能写完。**D2 之前不要碰 WebSocket。**

**任务顺序（做完一项再下一项）**

1. **D1 上午｜跑通裸 LLM。** 纯 Python + `openai` SDK，输入 `["身份证","丢失","补办"]`，输出两段文本。**不碰工具、不碰 FastAPI。**
2. **D1 下午｜包成严格 JSON。** `response_format={"type":"json_object"}` + prompt 里给字段说明 + `json.loads` 失败重试一次。这步做不好后面全乱。

4. **D2 下午｜加澄清 + 兜底。** 规则很朴素：**词数 ≤ 1，或最高置信度 < 0.8，或命中多个事项** → 返回 `clarify`。同时保留 `rule_fallback.py`：API 超时/断网无缝降级。

## 6. 识别层三档路线（B 组只需知道接口，A 组执行）

接口不动，识别层内部从"单帧判决"改成"短片段判决"。

**第 1 档（保底，1–2 天）｜时序投票。** 仍逐帧分类，但要求**连续 N 帧（如 8 帧）同一结果才输出**。只是 `vision_service.py` 里加一个滑动窗口计数器，几乎零风险，能把抖动型误识别压掉一大半。

**第 2 档（推荐，3–5 天）｜短片段关键点时序模型。** 抽 16 帧 → 每帧手部关键点（21×2 维）→ 小 GRU / 1D-CNN → 输出一个词。每词 50–100 段就够，**CPU 都能训**，5 台机器随便分。性价比最高。

**第 3 档（有余力）｜确认手势分段。** 用讨论记录第 5 条已有的设想（一个 OK 手势）作为识别开始/结束信号。它解决"系统怎么知道一个词打完了"这个真问题，交互上也是加分项。

### 6.3 数据：建议自己录

公开数据集能对上的只有 [CSL/SLR500](https://ustc-slr.github.io/datasets/2015_csl/)（约 500 个孤立词），词表不是政务词表，能挑出的政务词很有限。[CSL-Daily](https://www.sign-lang.uni-hamburg.de/lrec/data/csldaily.html) 是连续语句，用不上。

**自录成本承担得起**：16 词 × 4 人 × 10 遍 ≈ 640 段，一个下午录完。

自录的最大好处不是数据量，而是**演示当天的光线、背景、人物与训练集完全一致**。用公开数据训练、现场用自己人演示，域差在现场翻车概率很高。

**李东瑞负责组织采集**（录完就出混淆矩阵）。
