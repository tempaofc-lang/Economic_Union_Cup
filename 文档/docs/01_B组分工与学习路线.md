```python
  "translation": "站在听障群众第一人称，把关键词连成一句自然、礼貌的中文问句",
  "answer": "站在政务导办员角度，简明给出窗口号与所需材料的回答",

要求：
1. translation 必须通顺，可补全省略的主语，但不得新增关键词里没有的业务事项。

                messages=[
```

**② 写 `inference.py`（推理封装）**

新建文件，只做一件事：**把模型输出翻译成我们约定的格式**。

```python
# 手语识别系统/inference.py
from ultralytics import YOLO
import cv2

MODEL_PATH = "weights/best.pt"      # A 组给的权重放这里（weights/ 已被 gitignore）
_model = None                        # 全局只加载一次，别每帧都 YOLO(...)


def get_model():
    global _model
    if _model is None:
        _model = YOLO(MODEL_PATH)
    return _model


def run_video(video_path, frame_stride=5, conf_thresh=0.25):
    """
    读视频 → 每 frame_stride 帧推理一次 → 返回逐帧结果

    返回: [ {"frame_idx": 0, "word": "身份证", "conf": 0.93, "bbox": (x1,y1,x2,y2)}, ... ]
    注意：conf_thresh 这里是模型的"低门槛"，真正的业务阈值在 app.py 的滑块里，不要在这里过滤太狠。
    """
    model = get_model()
    cap = cv2.VideoCapture(video_path)
    out, idx = [], 0

    while True:
        ok, frame = cap.read()
        if not ok:
            break
        if idx % frame_stride == 0:
            r = model(frame, verbose=False)[0]
            for box, conf, cls in zip(r.boxes.xyxy, r.boxes.conf, r.boxes.cls):
                out.append({
                    "frame_idx": idx,
                    "word": model.names[int(cls)],       # 类别名 = 手语词
                    "conf": float(conf),
                    "bbox": tuple(int(v) for v in box),
                })
        idx += 1

    cap.release()
    return out
```

**③ 写「串词」算法（这是 B 组真正的技术贡献）**

A 组给的是逐帧结果，直接丢给大模型会把一个词重复十遍。规则如下，参数先按这个来、之后用实验结果调：

```python
# 手语识别系统/inference.py（追加）

STABLE_FRAMES = 5        # 同一词连续出现 ≥5 次抽帧才认
SAME_WORD_GAP = 8        # 同一个词再次出现，中间至少隔 8 次抽帧（防"一个词打三遍"）
CONFIRM_WORD = "确认"     # 「确认手势」对应的类别名（问 A 组要，可能是 OK / 确认 / confirm）


def frames_to_words(frames, conf_thresh=0.75):
    """把逐帧结果压成词序列 + 是否触发成句"""
    words, last, run_word, run_len, cursor = [], None, None, 0, 0
    last_pos, confirmed = {}, False

    for f in frames:
        cursor = f["frame_idx"]
        if f["conf"] < conf_thresh:
            run_word, run_len = None, 0
            continue

        if f["word"] == run_word:
            run_len += 1
        else:
            run_word, run_len = f["word"], 1

        if run_len < STABLE_FRAMES:
            continue

        # 稳定了，准备记入
        if f["word"] == CONFIRM_WORD:
            confirmed = True
            run_len = 0
            continue
        if f["word"] in last_pos and cursor - last_pos[f["word"]] < SAME_WORD_GAP:
            continue
        if words and words[-1] == f["word"] and cursor - last_pos.get(f["word"], -99) < SAME_WORD_GAP:
            continue

        last_pos[f["word"]] = cursor
        words.append(f["word"])
        run_len = 0

    return words, confirmed
```

## 7. 协作规则

### 7.1 Git（只记五条命令）

```bash
git pull                              # 每次开工前，先拉
git status                            # 看看自己改了啥
```
